# LordFilm TV 0.3.1

## Improvements

- Added the Movies page with a poster grid, focused-title preview, and selection restoration.
- Remember the selected voice for each series across episodes, seasons, and app restarts.
- Match saved voices by name when track order changes, and retain the preference when a voice is temporarily unavailable.
- Resize the content area smoothly when the sidebar expands or collapses.
- Display search results in a single horizontal row with the catalog-style preview.
- Remove the visible Search heading and reduce spacing so results are closer to the input while typing.
- Remove the result row's left inset until a card receives focus.

## Maintenance

- Share the Movies and Series grid implementation.
- Remove unused labels and redundant catalog wrappers.
- Update download links to the latest published release.

## Requirements

Android 7.0+ and Android System WebView/Chromium 111 or newer.

Android versionCode: 4. Debug builds use `tv.lordfilm.app.debug`; release builds use `tv.lordfilm.app`. Unsigned release APKs require signing before installation.
